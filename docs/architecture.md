# 架构与兼容边界

## 数据流

1. `sources.mbt` 将受限内存源树展开为带文件/物理起始行的逻辑行，不访问磁盘或进程环境。
2. `lexer.mbt` / `expr_parser.mbt` 处理引号、运算符与有界表达式；`parser.mbt` 验证作用域并将依赖合入符号。
3. `schema.mbt` 隐藏可变 Definition/Choice；构建器 API 与解析器共享校验。`graph.mbt` 在求值前用迭代 DFS 给出循环路径。
4. `fragment.mbt` 保存有序请求；后写的覆盖层不仅更新值，也更新请求次序，防止 choice 的最后选择被旧顺序覆盖。
5. `resolve.mbt` / `reverse.mbt` / `modules.mbt` / `choice.mbt` / `range.mbt` 做有界固定点求值。选择强度来自上一轮，收敛后保存独立的可见性、原因与诊断。
6. `export.mbt` 确定顺序输出；`variants.mbt` 用真实求值检查删减请求；`inspect.mbt` 返回副本而非内部可变集合。

## 可验证的不变量

- n/m/y 构成有序格；与/或满足交换、结合、幂等和吸收规律。
- 隐藏提示的用户请求不生效；强 select 可超过直接依赖且必须留下诊断。
- 布尔 choice 激活后至多一个成员为 y；optional 未被请求激活时成员可见性为 n。
- 活动 range 采用首个有效声明；越界用户值不被简单截断，而回退到默认再执行默认钳制。
- `Resolution::values`、诊断和 UI 依赖数组都不暴露库内部集合。
- 不确定语法不能靠忽略行来“通过”；不支持的指令/属性要返回 ConfigError。

## 当前兼容差异（纳入完整符合性工作）

本库不是逐字克隆：同名多声明和预处理已进入主路径；完整菜单对象与 tristate choice 仍待实现；.config 输入是严格模式；数值是有符号 64 位且按类型归一化。缺少默认值的数字使用 Unset。配置输出是完整值快照，不复制 Kconfiglib 对输出行的省略策略。有限差分只比较支持范围的语义值和可见性，不比较输出文本格式。

## 成本与资源

基础求值有界迭代上限 `4 * symbols + 32`，反向依赖与元数据读取存在扫描；没有性能优势声明。精简和 UI 请求探测限制 256 符号，避免把交互接口误用于大型自动配置树。资源上限见根 README；不应把库直接当作不受信任输入的安全沙箱。

目标版本为 Linux v6.12；阶段差异不从项目终点排除。详见 [符合性清单](conformance.md)。
