# Kconfig 符合性目标与可重现证据

## 项目终点

目标版本固定为 **Linux v6.12 Kconfig**，依据该 tag 的 `Documentation/kbuild/kconfig-language.rst`、`kconfig-macro-language.rst` 和 `scripts/kconfig` 行为。项目终点是该版本语言、预处理、声明合并与最终配置求值的完整符合性。同名多声明、预处理、三态 choice、数值和配置兼容差异都是必须解决的工作，不再列为永久非目标。终端/网页 UI 与 Linux 内核构建系统本身不属于语言实现。

规范入口：
- https://github.com/torvalds/linux/blob/v6.12/Documentation/kbuild/kconfig-language.rst
- https://github.com/torvalds/linux/blob/v6.12/Documentation/kbuild/kconfig-macro-language.rst
- https://github.com/torvalds/linux/tree/v6.12/scripts/kconfig/tests

**0.2.0 是阶段版本，不是完整符合性认证。** 独立回归参考为 Kconfiglib **14.1.0**；它不等于 Linux v6.12，不能把二者版本混为一谈，也不能把有限差分通过当作全部语言通过。完整验收还须以 Linux v6.12 原生 conf 和上游测试为基线，记录每个测试的映射、输出与差异。

## 本次已经落地的语义

同名声明在源树遍历后合并为一个符号。作用域先作用于各声明节点，再合并。符号直接依赖和提示可见性取各节点的或；default/range/select/imply 保留声明依赖条件；默认值按源树顺序取第一个有效项。只有后续声明提供类型也可以使用，冲突类型仍报错。`source_locations` 返回全部声明位置。builder 的重复 add 仍是错误，不等同于语言声明。

预处理已接入 `parse_kconfig` / `parse_sources`，共用每次解析的宏上下文，支持 `=`、`:=`、`+=`、嵌套引用、参数函数、环境快照，以及 shell/info/warning-if/error-if/filename/lineno。引号中的展开内容作为数据，宏不能生成指令关键字或跨越未引用 token。帮助正文不展开，include 顺序影响立即/延迟求值。

宿主通过 `Preprocessor::new(environment=..., shell=..., message=...)` 提供环境和副作用；默认不隐式读取宿主状态，调用 shell 而无 executor 会报错。宿主返回 shell stdout，库按规范折叠换行。内存源树支持排序后的 `*` / `?`、source/rsource/osource/orsource 和不越过源树根的父路径。预算与循环检查继续生效。

## 跨文件声明及最终配置

完整可运行输入见 `examples/declarations/main.mbt`：根文件定义两个默认值宏并依次加载 a/Kconfig、b/Kconfig；两个文件分别在 LEFT、RIGHT 条件下声明同名 int SHARED，默认 11、22。

| 输入请求 | 最终 SHARED | 语义依据 |
| --- | --- | --- |
| LEFT=n, RIGHT=n | Unset | 两个声明均不活动 |
| LEFT=y, RIGHT=n | 11 | 首个声明活动 |
| LEFT=n, RIGHT=y | 22 | 第二个声明独立活动，依赖不是 AND |
| LEFT=y, RIGHT=y | 11 | 首个活动 default 优先 |
| RIGHT=y, SHARED=37 | 37 | 可见提示接受显式请求 |

执行：

```sh
moon run examples/declarations --target js
python tools/check_declarations.py --target js
```

第一个命令实际输出：

```config
# Generated by MoonKconfig; do not edit derived values.
# CONFIG_LEFT is not set
CONFIG_RIGHT=y
CONFIG_SHARED=22
```

第二个命令把实际 MoonBit 输出交给 Kconfiglib 读取，与独立求值得到的值比较。差分另比较值、可见性和自身回读，包含四种跨文件组合、类型后置、局部反向边和跨文件宏状态。夹具为原创合成数据，没有复制上游实现/测试。
